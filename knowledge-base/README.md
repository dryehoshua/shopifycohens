# Base de conocimiento · Cohens Operations

Esta carpeta documenta cómo se usa Shopify en Cohen Store y qué decisiones se han
tomado. No contiene credenciales ni datos personales.

## Índice

- `CAPACIDADES_NATIVAS_SHOPIFY.md`: qué resuelve Shopify sin desarrollo.
- `PROCEDIMIENTOS_OPERATIVOS.md`: procedimientos propuestos para el equipo.
- `FUENTES_OFICIALES.md`: documentación de Shopify consultada.

El diagnóstico con cifras reales se conserva fuera del repositorio público.

## Alcance de Shopify Knowledge Base

La app instalada "Knowledge Base" administra preguntas frecuentes para compradores
y agentes de compra. Esta carpeta es la base interna de TI y operación. Las dos se
complementan, pero no son intercambiables.

## Regla de actualización

Cada cambio operativo debe registrar fecha, responsable, motivo, prueba realizada y
resultado. Las capturas, exportaciones o bases de datos con información de clientes
deben almacenarse fuera del repositorio.
